# josephhall5959.github.io

Academic website of Joseph P. Hall. Hand-written HTML, no build step, no
trackers. Designed to be equally navigable by humans and AI agents — agents
should start at [`llms.txt`](llms.txt).

- `index.html` / `style.css` — the site
- `papers/` — canonical PDFs of working papers
- `cv/cv.tex` — CV source; build with `tectonic cv.tex` and copy to
  `assets/Joseph_Hall_CV.pdf`
- `llms.txt`, `robots.txt`, `sitemap.xml` — machine entry points

Deployed automatically by GitHub Pages from `main`.
