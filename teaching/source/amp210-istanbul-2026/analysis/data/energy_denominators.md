# Energy denominators for Bitcoin's share (checked 2026-10-05)

| Quantity | Value | Source (quoted) |
|---|---|---|
| Bitcoin electricity use | 138 TWh/yr | Cambridge Digital Mining Industry Report (2025) |
| World electricity demand, 2024 | 30,856 TWh | Ember, Global Electricity Review 2025: "Global electricity demand rose to 30,856 TWh, crossing 30,000 TWh for the first time." https://ember-energy.org/latest-insights/global-electricity-review-2025/global-electricity-trends/ |
| Cross-check | ~31,000 TWh generation | Energy Institute Statistical Review 2025: Asia Pacific 16,132 TWh = 52% of global generation |
| World primary energy, 2024 | 592 EJ = 164,400 TWh | Energy Institute Statistical Review 2025 |

Bitcoin / electricity = 138 / 30,856 = 0.447% -> 0.4% (one significant digit). Cambridge's own "~0.5%" used an unstated denominator; superseded.
Bitcoin / primary energy = 138 / 164,400 = 0.084% -> 0.08%.
Data centres / electricity = 415 / 30,856 = 1.34% -> 1% (IEA's own "~1.5%" superseded for consistency of denominator).
Data centres / primary energy = 415 / 164,400 = 0.252% -> 0.3%.
Ethereum Merge: (21 - 0.0026) / 21 = 99.988% -> about 99.99% (matches the figure label).
